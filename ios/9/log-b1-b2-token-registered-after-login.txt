What this proves
----------------
B2  APNs hands the token back during launch, while nobody is signed in.
    `syncTokenIfNeeded()` sees no account and does nothing — there is no
    401 on `v1/device-tokens` anywhere in this log. The POST is only
    issued after `POST v1/login` returns 200, and it carries the freshly
    minted bearer token. The backend answers 201.

B1  The success path logs `✅ Device token registered with backend` and
    nothing else. The old code decoded the bare JSON string response
    into a struct and always logged a decode failure here; the
    body-less `request(_:)` overload no longer does.
